Official Windows installer downloads for Honakari, the reader previously called YomiShelf and PANDA Reads. Application source is maintained separately.

Website: https://honakari.pages.dev/

Use the assets on the latest published release. Python is included. Installers are unsigned. Windows 10 has owner testing; Windows 11 is not manually verified. No Mac build is offered.

Existing application identifiers and storage paths are preserved for upgrades. Back up your library before upgrading; books, notes and valid signed licences are retained. The internal executable can still be named PANDAReads.exe.
